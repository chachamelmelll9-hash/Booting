# Skill Trigger Map

## Resume

- resuming work or checking project status -> `continue`

## Planning Chain

- first-run project bootstrap or boilerplate app launch -> `setup`
- rough project idea after bootstrap -> `start`
- legacy initialize request -> `init`
- core feature clarification -> `clarify-core-feature`
- approved specs to pages -> `define-pages`
- approved pages to wireframes -> `design-wireframes`
- approved wireframes to architecture -> `design-architecture`
- approved architecture to scenarios -> `write-test-scenarios`

## Build And Verify

- approved docs to implementation -> `implement-feature`
- mobile UI design, wireframes, or UI review -> `mobile-ux-ui-design`
- icon asset update -> `setup-icons`
- landing page generation or refresh -> `setup-landing`
- browser automation request -> `agent-browser`
- DB design or SQL quality guidance -> `supabase-postgres-best-practices`

## Release

- deployment workflow -> `deploy`
- raw release screenshots to framed store images -> `make-aso-images`
- store release workflow -> `launch`
