## 만드는 법

`scripts/promo-video/` 에 파이프라인이 그대로 있다. 에뮬레이터 스크린샷 → 장면 HTML → 헤드리스 Chrome PNG → ffmpeg 합성.

```powershell
cd scripts\promo-video
# 1) 앱 화면 다시 찍기 (에뮬레이터가 로그인된 상태여야 한다)
.\shot.ps1 -Name 01_home_gems -Tap "135,2299" -Dump   # -Dump 로 탭 좌표를 얻는다
# 2) 부모님 웹은 헤드리스 Chrome 으로 (node scripts/open-parent-web.mjs <id> --print 로 주소)
.\render.ps1 -Url "http://localhost:3000/p/<token>" -Out shots\13_tall.png -W 480 -H 3000 -Scale 2.25
# 3) 폰 화면 비율(1080x2230)로 정규화
.\crop.ps1
# 4) 장면 11개 렌더
.\renderscenes.ps1
# 5) 합성 (약 3분)
.\build.ps1
```

### 걸렸던 것

- **`adb screenrecord` 는 못 쓴다.** 에뮬레이터가 swiftshader(소프트웨어 렌더링)라 프레임이 1장만 잡힌다. 그래서 스크린샷을 모아 ffmpeg 으로 움직임을 만든다 — 결과적으로 더 깔끔하다.
- **`zoompan` 의 `d` 는 입력 프레임마다 곱해진다.** `-loop 1 -t 6` 으로 넣으면 6초가 아니라 6×6초가 나온다(실제로 60초가 370초가 됐다). 입력을 단일 PNG로 주고 `d=<총 프레임>` 으로 길이를 만든다.
- **PowerShell 5.1 은 BOM 없는 UTF-8 `.ps1` 을 ANSI 로 읽는다.** 한글 주석의 깨진 바이트가 뒷줄을 삼켜 변수가 통째로 사라진다. `scripts/promo-video/*.ps1` 은 전부 ASCII 로만 쓴다.
- `"$XF:offset=..."` 처럼 변수 뒤에 콜론이 붙으면 PowerShell 이 스코프 한정자로 읽는다. `$($XF):` 로 감싼다.
