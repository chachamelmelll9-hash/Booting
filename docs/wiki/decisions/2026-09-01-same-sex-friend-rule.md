# 동성 친구 규칙, 관계 목적 정리

## 배경
PRD 6장: 관계 목적 7종 중 최대 2개, "동성 친구를 선택한 경우 동성 프로필을 추천할 수 있어야 한다". 소유자(09-01): "동성친구면 동성프로필만 뜨게끔 해여할듯", "가벼운 만남은 뺴줘".

## 결정
- **대칭 규칙** (`DiscoveryRepository`): 내 목적에 `same_sex_friend` 가 있으면 → 같은 성별 + 상대도 그 목적을 가진 프로필만. 없으면 → 목적이 `same_sex_friend` **하나뿐**인 프로필은 제외. **성별 필터보다 우선** — 목적이 더 강한 신호다.
- 프로필 작성·필터 시트에서 이 목적을 고르면 칩 아래에 즉시 안내: "동성 친구를 선택하시면 같은 성별의 동성 친구를 찾는 분만 추천됩니다." 추천 결과가 통째로 달라지는 선택이라 나중에 알면 늦다.
- **'가벼운 만남'(casual) 제거** — enum 재생성 마이그레이션 `20260901120000`. 남은 목적: 재혼 고려 / 진지한 연애 / 여행·취미 친구 / 동성 친구 / 식사·산책 친구 / 아직 잘 모르겠어요(단독).
- 같은 커밋 묶음에서 가족·생활 정보 7항목 + 사진(최소 3장)을 필수로, 동거 가족은 4개 보기 복수 선택, 흡연은 비흡연/흡연 단일 선택 — 자유 입력이면 "혼자삽니다/독거/혼자 거주" 가 다른 값으로 쌓여 표기가 제각각이 된다 (`93047b0`).

## 근거
이성 교제가 아닌 목적에 이성을 보여주면 양쪽 다 헛걸음이다. 반대 방향도 같다.

## 이후
PRD 6장에는 '부담 없는 데이트' 가 남아 있다 — 코드에는 없다. 관련: [discovery-ranking](../concepts/discovery-ranking.md).
