# 민트, 워드마크, 탭

## 배경
소유자(09-01): "Booting 이라는로고 초록색으로 동글동글하게 만들어서 왼쪽상단에 보여주고 우리 부모님 소개팅, 직접 주선해주세요(부랑 팅은 초록색) 어때", "전체적으로 민트 세련된 UI" → 첫 안 뒤 "노노 너무밤티야 로고 원 빼고 폰트를 동글동글하게 그리고 우리부모님 소개팅 이문구는 로고밑이 아니라 부모님 프로필 등록하기 화면에 넣어야지!!! 광고 없다는 문구 뺴주고", "하단 아이콘 밑에 홈 관심 인연 내 정보 이런 글자 다 뺴줘 아이콘이면 충분해".

## 결정
- 팔레트 emerald → **mint/teal** (`#14B8A6` 계열), 중립 gray → **slate**. 초록은 성공 신호로 이미 쓰는 색이라 브랜드색이면 "완료됨" 처럼 읽히고, 따뜻한 회색 위의 민트는 탁하다.
- 워드마크 `booting` → 글자만, 배경 도형 없음(알약 배지는 버튼처럼 보였다). 09-02 `Booting` 첫 글자 대문자.
- 태그라인 "우리 **부**모님 소개**팅**, / 직접 주선해주세요" 는 **등록 안내 화면에만** — 홈에서 반복하면 광고 문구처럼 읽힌다. 줄바꿈은 소유자 지정.
- 안내 항목에서 **'광고 없음' 문구 제거** (정책은 유지). 뒤에 "전면 무료입니다" 도 제거(`0c4c86d`).
- 탭 라벨 숨김, 아이콘만. `tabBarAccessibilityLabel` 로 스크린리더 유지.
- 프로필 공개 전에는 관심·인연 탭을 `href:null` 로 감춤 — 서버가 403 을 주는 탭을 띄워두면 눌러봐야 빈 화면. '내 정보' 는 남김(로그아웃·등록 상태 확인 경로).
- 홈 빈 상태의 설명 문단 제거(제목 + CTA 만).
- (09-02) 홈 탭 아이콘 집 → **`B`**. "홈은 '집' 이 아니라 추천이 오는 곳이다." 시스템 서체·배지 없음 — "주변에 사각형 이런건 뺴줘 딱 B로만" → "B로고 이상해 그냥 정직한 폰트로해줘".
