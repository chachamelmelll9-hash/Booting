# 하루 6장 원석 카드

이 커밋(09-06 23:16)은 **이 머신의 세션 기록에 없다** — 다른 환경에서 작업됐다. 소유자가 다음 날 "어제 추천프로필이랑 받은 프로필 다 카드 뒤집는걸로 바꿔달라고햇는데" 라고 한 것으로 요청 내용을 안다.

## 결정
- 홈: 무한 카드 덱 → **하루 6장** 원석 카드 그리드. 24시간 살고 자정에 새로 뽑힌다 (`useDailyPicks`). 누르면 그 자리에서 뒤집혀 최대로 펼쳐진다.
- 뒷면은 흰 바탕 + 민트 테두리, 색은 원석에만. 구분은 **모양** 6종. 이름이 맨 위.
- **받은 관심도 같은 그리드.** 다른 점은 펼친 카드 안에만(인사말 맨 위, '관심 답하기', 넘기기).
- **보관함(찜) 폐지.** 받은 관심 카드가 2주 뒤 자동 삭제되므로 "지금 결정하기 어려운 분" 을 담아 둘 자리가 따로 필요 없다 — 두면 그게 보류다. 서버 `hiddenSenderIds` 의 찜 제외 규칙도 함께 제거(화면만 지우면 찜해 둔 사람들이 되돌릴 방법 없이 사라진 채 남는다).
- 받은 관심 2주 삭제가 문구만 있고 동작이 없었다 → `run_maintenance()` 규칙 4 (`20260906120000`). 연결로 이어진 하트는 지우지 않는다.
- **프로필 상세의 넘기기 제거** — 추천은 24시간 뒤 알아서 사라지므로 되돌릴 수 없는 넘기기로 지우게 하면 이득 없이 위험만 진다. 가족관계 배지도 제거.

## 같이 고친 버그
- `/profile/:id` 라우팅 충돌 — `app/profile/[id].tsx` 와 `app/(parent)/profile/[connectionId].tsx` 가 같은 경로로 해석돼 자녀가 부모님 화면으로 갔다 → `(parent)/shared-profile/…` 로.
- 부모님 코드 자릿수 불일치(DB 8 / 앱·서버 6) → 커밋되지 않았던 마이그레이션 복원.
- 펼친 카드 사진이 빈 회색 — 앞면에 `rotateY(180deg)` 가 남으면 안드로이드가 Image 를 안 그린다 → 앞면은 360° 로 끝낸다.
