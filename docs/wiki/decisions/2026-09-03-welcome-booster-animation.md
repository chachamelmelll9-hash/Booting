# 부스터 인사 화면

## 배경
소유자(09-03): "로그인하면 민트색 부스터가 뜨면서 부스터 뚜껑이 열리는 모션과 함께 액체가 흘러넘치는 모션 뒤에 Booting은 부모님의 새 인연을 응원합니다. 밑에 다음 버튼 누르면 프로필 등록화면 나오게 가능? 재밋는 UI를넣고싶어서그래".

## 결정
- `(parent-setup)/welcome.tsx`. 병이 제자리에서 차오르고 → 뚜껑이 톡 튕겨 옆으로 굴러떨어지고 → (처음엔 액체, 09-04 부터 **하트 18개**가 600ms 에 걸쳐) 쏟아지고 → "Booting은 부모님의 새 인연을 응원합니다" → [다음] 은 **하던 자리**로.
- **언제**: 로그인·가입·카카오·개발용 모두 직후 한 번. 앱을 새로 켤 때도 거치되(`f621ef9`) 등록을 마친 사람은 인사 없이 홈으로 — 갈림길 판정을 `nextSetupStep` 한 곳에.
- RN 내장 `Animated` 만 — 도형이 사각·원 몇 개뿐이라 SVG/Lottie 를 끌어올 이유가 없다.
- 서비스 안내 첫 줄 "자녀분이 대신 등록하고 프로필을 고르며, 부모님은 최종 결정만 하시면 됩니다" (소유자 지정), "전면 무료입니다" 제거.

## 실측으로 버린 것 (전부 소유자 피드백)
병이 위로 솟는 것("병이 위쪽으로날아가면안되지") → 제자리 확대 / 뚜껑이 로켓처럼 → 톡 튕겨 굴러떨어짐 / 감속하는 물줄기 → 가속 / 양옆 두 줄기("너무이상해 ㅋㅋㅋㅋ") → 넓게 퍼지는 겹 → 손 모양으로 보임("뻐큐 뒤집어놓은 형태") → 병 폭 전체 한 겹 → 결국 **액체 → 하트**("물넘치는걸 하트들이 흘러넘치는걸로 어떙"). 브랜드 민트로 칠하면 병 앞에서 사라져 진한·연한 민트만. 바닥에 쌓이는 하트는 가시처럼 보여 뺌.

## 근거
"자녀가 부모님을 대신 등록하는 일은 원래 조금 쑥스러운 일이라, 시작하는 자리만큼은 가볍고 즐거워야 한다." 켤 때마다 같은 인사를 보는 건 즐거움이 아니라 방해 — 그래서 조건부.
