# docs/

| 폴더 | 무엇 |
|---|---|
| [`wiki/`](wiki/index.md) | **LLM 위키** — 여기서 시작한다. 규약은 [`wiki/schema.md`](wiki/schema.md) |
| `features/` | 기획 정본(기능 스펙·데이터 모델·페이지 맵·와이어프레임·테스트 시나리오). 위키의 원본 소스 |
| `progress/` | 파이프라인 진행 기록(`pipeline.jsonl` 등)과 Windows 환경 메모 |
| `archive/` | 템플릿 시절 문서·스크린샷 |

Obsidian 은 이 `docs/` 폴더를 볼트로 연다 — `apps/wiki` 정션이 여기를 가리킨다 (`scripts/link-wiki.ps1`).
