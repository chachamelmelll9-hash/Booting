# Shippen Demo Video Script

3-minute English demo video script for `Shippen`.

## 0:00 - 0:15

**Voiceover:**

Welcome to Shippen, a production-ready starter kit for building cross-platform mobile products faster. Instead of spending weeks wiring up infrastructure, authentication, navigation, backend APIs, and WebView integration, you start with a solid foundation on day one.

## 0:15 - 0:35

**Voiceover:**

The first thing that makes this product stand out is setup speed. Shippen includes an interactive setup script that configures the project for your brand, your app name, your bundle ID, and your organization. It updates the monorepo structure automatically, installs dependencies, and gets your project ready to run with minimal manual work.

## 0:35 - 1:05

**Voiceover:**

Once the project is running, you get a complete mobile app built with React Native and Expo. Out of the box, it includes core screens and flows like login, signup, logout, tab-based navigation, profile settings, and language preferences. This means you are not starting from a blank screen. You are starting from a working product base that is already organized for real development.

## 1:05 - 1:35

**Voiceover:**

Shippen also includes a WebView app that connects cleanly with the mobile experience. This is useful when you want to move faster on web-based internal pages while keeping the native shell for the overall app. The mobile app and WebView communicate through a built-in bridge, so session handling and protected content work together in a structured way.

## 1:35 - 2:00

**Voiceover:**

On the backend side, the project ships with a NestJS server and a production-oriented architecture. Authentication is already connected, the API structure is modular, and the codebase is designed to scale. You also get shared packages for things like localization, Supabase integration, and mobile-to-WebView communication.

## 2:00 - 2:25

**Voiceover:**

From a developer experience perspective, everything lives inside a clean monorepo. Mobile, server, WebView, and shared packages are all in one place. That makes it much easier to build features consistently, share types, and keep your product aligned across platforms.

## 2:25 - 2:45

**Voiceover:**

And this is not just for prototyping. Shippen is built with production in mind. It includes type checking, testing structure, Docker support, and deployment-ready workflows, so you can move from idea to launch with much less friction.

## 2:45 - 3:00

**Voiceover:**

If you want to ship a mobile product without rebuilding the same foundation every time, Shippen gives you a faster starting point and a cleaner path to production. Build faster, customize freely, and focus on the product that makes your business different.
