# Archive

Historical documents from the project this template was extracted from
(a BLE/MQTT device app on EC2) plus vendor-internal planning material and
old UI screenshots.

**Nothing in this directory describes the current template.** Do not use
these files as a reference for the current architecture, pages, or
deployment flow — see `docs/auth-architecture.md` and `docs/features/`
for current documentation.

This directory is intentionally excluded from `scripts/branding.sh`
renames and is safe to delete entirely in your own project.
