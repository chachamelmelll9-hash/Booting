# Wireframe: Common States

공통 상태 화면 — 여러 페이지에서 동일하게 사용되는 상태별 와이어프레임.
개별 탭 와이어프레임에서 "Common State 사용"으로 표기된 경우 이 파일을 참조한다.

## Empty State

```
+----------------------------------+
|  9:41          [=] LTE  100%     |
+----------------------------------+
|             화면 제목             |
+----------------------------------+
|                                  |
|                                  |
|        (아웃라인 벡터 아이콘)      |   <- 64x64, 뉴트럴 그레이
|                                  |
|   아직 받은 관심이 없어요           |   <- 20sp Bold, 좌측 정렬 아님(이 화면만 중앙)
|                                  |
|   우리 부모님 프로필이 공개되어      |   <- 15sp, 2줄 이내, 왜 비었는지
|   있으면 더 많은 분이 볼 수 있어요   |
|                                  |
|      [ 프로필 상태 보기 ]          |   <- Secondary 버튼, 44pt+
|                                  |
|                                  |
+----------------------------------+
|  [홈]  [관심]  [인연]  [내 정보]   |
+----------------------------------+
```

**적용 페이지**: 받은 하트, 인연 목록(상태별), 차단 목록, 신고 내역, 알림

**Annotations:**
- [1] 아이콘: 이모지 금지 — 벡터 아이콘 세트 사용 (anti-patterns.md)
- [2] 문구: **왜 비었는지 + 무엇을 하면 되는지** 2줄 고정 패턴. "데이터 없음" 한 줄 금지
- [3] CTA: 빈 상태를 벗어나는 **다음 행동**을 지목한다. 없으면 CTA를 생략하고 문구만 둔다
- **Visual Hierarchy**: 제목 문구 > CTA > 설명 문구 > 아이콘
- **Note**: 빈 상태는 앱에서 유일하게 중앙 정렬을 허용하는 레이아웃이다. 나머지 화면은 좌측 정렬 기준

## Loading State

```
+----------------------------------+
|  9:41          [=] LTE  100%     |
+----------------------------------+
|             화면 제목             |
+----------------------------------+
|                                  |
|  +----+  ▒▒▒▒▒▒▒▒▒▒▒▒▒          |   <- 실제 아이템과 같은 크기·간격
|  |▒▒▒▒|  ▒▒▒▒▒▒▒▒                |
|  +----+  ▒▒▒▒▒▒                  |
|                                  |
|  +----+  ▒▒▒▒▒▒▒▒▒▒▒            |
|  |▒▒▒▒|  ▒▒▒▒▒▒▒                 |
|  +----+  ▒▒▒▒▒                   |
|                                  |
|  +----+  ▒▒▒▒▒▒▒▒▒▒▒▒▒▒         |
|  |▒▒▒▒|  ▒▒▒▒▒▒▒▒▒               |
|  +----+  ▒▒▒▒▒▒                  |
|                                  |
+----------------------------------+
```

**적용 페이지**: 받은 하트, 인연 목록, 차단 목록, 신고 내역, 알림, 채팅방(메시지 영역)

**Annotations:**
- [1] 스켈레톤은 **실제 레이아웃과 같은 크기·간격**으로 3행. 범용 원형 스피너 금지
- [2] 시머는 `withRepeat(withTiming(0.7, { duration: 800 }), -1, true)` — linear 페이드 금지
- [3] 300ms 미만에 응답이 오면 스켈레톤을 띄우지 않는다 (깜빡임 방지)
- [4] 버튼 내부 로딩은 스켈레톤이 아니라 **버튼 자리 스피너 + 비활성화**로 처리

## Error State

```
+----------------------------------+
|  9:41          [=] LTE  100%     |
+----------------------------------+
|             화면 제목             |
+----------------------------------+
|                                  |
|        (경고 벡터 아이콘)          |
|                                  |
|   목록을 불러오지 못했어요          |   <- 원인
|                                  |
|   네트워크 연결을 확인하고          |   <- 해결 방법
|   다시 시도해주세요                |
|                                  |
|      [====다시 시도====]          |   <- 복구 경로 필수
|                                  |
|        [ 고객센터 문의 ]           |   <- 2회 이상 실패 시에만 노출
|                                  |
+----------------------------------+
```

**적용 페이지**: 모든 서버 조회 화면

**Annotations:**
- [1] 문구는 **원인 + 해결 방법** 2단. "오류가 발생했습니다" 단독 금지
- [2] `다시 시도`는 항상 제공한다. 복구 경로 없는 에러 화면 금지
- [3] 같은 요청이 2회 연속 실패하면 `고객센터 문의`를 추가로 노출한다
- [4] 부분 실패(리스트 일부만 로드)는 전체 에러 화면 대신 **하단 인라인 재시도 행**으로 처리한다

## Inline Field Error (폼 공통)

```
|  이름 *                          |
|  +----------------------------+  |
|  { 김영희                     }  |   <- 빨간 1.5dp 테두리
|  +----------------------------+  |
|  (!) 만 50세 이상만 등록할 수 있어요 |   <- 아이콘 + 텍스트, 필드 바로 아래
```

**적용 페이지**: 프로필 작성/수정, 부모님 동의, 만남 일정, 미동행 확인, 신고

**Annotations:**
- [1] 에러는 **해당 필드 바로 아래**. 폼 상단 요약 배치 금지
- [2] 색상만으로 알리지 않는다 — 빨간 테두리 + (!) 아이콘 + 문구 3종 세트
- [3] 검증 시점은 blur. 타이핑 중 에러 표시 금지
- [4] 제출 실패 시 **첫 오류 필드로 자동 포커스 + 스크롤**

## Destructive Confirm (파괴적 동작 공통)

```
        +------------------------+
        |  프로필 공개를          |
        |  중단할까요?            |
        |                        |
        |  비공개로 바꾸면 새로운  |
        |  추천에 노출되지 않아요. |
        |  받은 하트와 대화는      |
        |  그대로 유지됩니다.      |
        |                        |
        |  [ 취소 ]  [ 공개 중단 ] |   <- 우측이 위험색(빨강)
        +------------------------+
```

**적용 페이지**: 프로필 공개 중단, 차단, 대화 나가기, 회원 탈퇴, 동의 철회

**Annotations:**
- [1] 파괴적 버튼은 **위험 색상 + 우측 배치**로 일반 액션과 시각적·공간적 분리
- [2] 본문에 **결과**를 구체적으로 적는다("~하면 ~됩니다"). "정말 하시겠습니까?" 단독 금지
- [3] 되돌릴 수 있는 동작(공개 중단, 차단)은 실행 후 토스트에 `실행 취소`를 5초간 제공한다
- [4] 되돌릴 수 없는 동작(회원 탈퇴)은 실행 취소를 제공하지 않는 대신 확인 문구 입력을 요구한다

## Toast

```
|                                  |
|  +----------------------------+  |
|  | (v) 관심을 보냈어요          |  |   <- 3초 자동 해제
|  +----------------------------+  |
|                                  |
+----------------------------------+
|  [홈]  [관심]  [인연]  [내 정보]   |
```

**Annotations:**
- [1] 탭바 위 16dp 띄워 배치. 포커스를 빼앗지 않는다
- [2] 3초 자동 해제. 되돌리기가 있으면 5초
- [3] 에러는 토스트로 끝내지 않는다 — 화면 안에 복구 경로를 남긴다
