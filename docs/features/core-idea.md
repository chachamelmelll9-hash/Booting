# Core Feature Idea

**이혼·사별한 부모님이 소개팅 앱을 직접 쓰기는 어렵고 자녀는 안전하게 주선할 방법이 없다 → 인증된 성인 자녀가 부모님 프로필을 대신 등록하고 상대를 탐색하되, 프로필 공개와 만남의 결정권은 부모님에게 두고 실제 만남 확인까지 이어주는 자녀 주도형 황혼 매칭.**

## 무엇을 만드는가

자녀가 본인인증과 가족관계 인증을 마친 뒤 부모님의 동의를 받아 프로필을 등록한다.
조건 기반 추천에서 자녀가 상대 부모님 프로필에 하트를 보내고, 양측 자녀의 상호 하트로
자녀 간 대화가 열린다. 자녀끼리 조율해 부모님께 소개하고, 자녀 동반으로 첫 만남을 갖는다.

## 다른 매칭 앱과 결정적으로 다른 점

| | 일반 매칭 앱 | 부팅 |
|---|---|---|
| 앱을 쓰는 사람 | 본인 | **자녀** (부모님은 동의·결정 주체) |
| 가입 자격 | 제한 없음 | 자녀 본인인증 + 가족관계 인증 필수 |
| 등록 대상 | 본인 | **사별 또는 이혼**한 부모님만 (별거 제외) |
| 상호 호감 | "매칭 성공" | **"대화 연결"** — 성공이 아니다 |
| 최종 성공 | 매칭 시점 | **부모님이 실제로 만나고 양측 자녀가 확인한 시점** |

## 핵심 제약 (임의로 바꾸지 않는다)

- 프로필 공개와 실제 만남에는 **부모님의 명시적 동의**가 필요하고, 철회 시 즉시 비공개한다.
- 상호 하트 단계에서 '매칭 성공'이라는 표현을 쓰지 않는다 (알림 문구 포함).
- 첫 만남은 자녀 동행이 기본값이다 (강력 권장 — 미동행 시 사유 입력 + 안전수칙 재확인).
- 가족관계증명서 원문·주민등록번호 등 민감정보는 다른 사용자에게 공개하지 않는다.
- 전면 무료 (인앱결제·AdMob 모두 비활성). 단, **화면 문구로 '광고 없음'을 내세우지 않는다** — 정책은 지키되 홍보 문구로 쓰지 않는다.

## North Star Metric

단순 하트 수가 아니라 **양측 부모님이 실제 만남을 완료한 건수**.
