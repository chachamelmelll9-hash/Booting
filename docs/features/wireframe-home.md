# Wireframe: Tab 홈

## Overview

- Tab: 홈
- Pages: 2 (추천 피드, 추천 조건)
- Source Features: 조건 기반 추천 & 탐색 (+ 등록 전 빈 상태는 부모님 프로필 등록 & 동의)

## Feature: 조건 기반 추천 & 탐색

### 1. 추천 피드

- **Route**: `app/(tabs)/home/index.tsx`
- **Type**: Tab
- **Pattern**: 고유 (카드 스택)

#### Default State

```
+----------------------------------+
|  9:41          [=] LTE  100%     |
+----------------------------------+
|  booting                          |  <- 워드마크만. 종 아이콘 없음
|  30km · 송파구 · 사별,이혼   (필터) |  <- 조건 요약 칩
+----------------------------------+
|                                  |
|  +----------------------------+  |
|  |                            |  |
|  |                            |  |
|  |          [img]             |  |  <- 대표사진 full-bleed
|  |       대표사진 4:5          |  |     카드 높이의 약 62%
|  |                            |  |
|  |                            |  |
|  |  ......gradient overlay....|  |
|  |  텃밭지기, 67세             |  |  <- 24sp Bold, 좌측 정렬
|  |  서울 송파구 · 사별          |  |  <- 15sp
|  +----------------------------+  |
|  |  [여행·취미 친구][진지한 연애] |  |  <- 관계 목적 칩 최대 2
|  |                            |  |
|  |  등산과 전시 관람을 좋아하는   |  |  <- 자녀 소개글 2줄 말줄임
|  |  따뜻한 아버지예요...        |  |
|  |                            |  |
|  |  (v)자녀인증 (v)가족관계      |  |  <- 인증 배지, 고정 위치
|  +----------------------------+  |
|                                  |
|   [넘기기]   [자세히]   [ 하트 ]   |  <- 56pt 높이, 하트가 가장 큼
+----------------------------------+
|  [홈]  [관심]  [인연]  [내 정보]   |
+----------------------------------+
```

**Annotations:**
- [1] 조건 요약 칩: 현재 필터를 한 줄로. 탭하면 `filters` 바텀시트
- [2] 헤더에는 워드마크만 둔다. 종 아이콘은 걷어냈다 — 새 관심·새 대화는 관심·매칭 **탭 배지**가 알리고, 같은 사실을 헤더에서 한 번 더 빨갛게 알리면 어느 쪽을 눌러야 하는지가 매번 질문이 된다
- [3] 카드: 사진이 카드 상단을 **가장자리까지** 채운다. 카드 안에서 텍스트만 16dp 좌우 패딩
- [4] 하단 액션: `하트`가 폭·색 모두 우세(Primary), `자세히`는 Secondary, `넘기기`는 Ghost — **균등 3분할 금지**
- [5] 인증 배지: 스크롤·말줄임으로 사라지지 않는 고정 슬롯. 이 서비스의 신뢰 근거
- **Visual Hierarchy**: 대표사진 > 이름·나이 > 지역·혼인상태 > 관계 목적 > 소개글 > 인증 배지
- **Interaction**: 좌/우 스와이프 = 넘기기/하트 (스프링 `damping: 18`). **스와이프 전용 기능 없음** — 동일 동작을 버튼으로도 제공 (a11y 필수)
- **Spacing**: 화면 좌우 16 / 카드↔액션 24 / 액션↔탭바 16 (8dp 그리드)
- **Performance**: 카드 스택은 앞의 2장만 마운트하고 나머지는 프리페치만. `ScrollView` + `.map()` 금지

#### Empty State — 부모님 프로필 미등록

```
+----------------------------------+
|  9:41          [=] LTE  100%     |
+----------------------------------+
|  부팅                        (종) |
+----------------------------------+
|                                  |
|  +----------------------------+  |
|  |                            |  |
|  |     (가족 벡터 아이콘)       |  |
|  |                            |  |
|  |  아직 등록된 부모님이 없어요   |  |  <- 20sp Bold
|  |                            |  |
|  |  부모님 프로필을 등록해야      |  |
|  |  인연을 찾아드릴 수 있어요     |  |
|  |                            |  |
|  |  [====부모님 등록하기====]   |  |  <- Primary, 56pt
|  +----------------------------+  |
|                                  |
|  ---                             |
|  이렇게 진행돼요                   |
|  1  자녀 본인인증과 가족관계 인증    |
|  2  부모님께 동의를 받아요          |
|  3  프로필을 등록하고 공개해요       |
|                                  |
+----------------------------------+
|  [홈]  [관심]  [인연]  [내 정보]   |
+----------------------------------+
```

**Annotations:**
- [1] 이 상태에서는 추천 API를 **호출하지 않는다** (프로필 없이 추천은 의미 없음)
- [2] 3단계 안내: 등록이 6단계 플로우라 진입 전에 총량을 미리 알린다 (이탈 방지)
- [3] CTA → `(parent-setup)/onboarding` (탭 밖 Modal 그룹)
- **Visual Hierarchy**: CTA > 제목 문구 > 3단계 안내 > 아이콘

#### Empty State — 추천 소진

```
|                                  |
|        (다 본 카드 아이콘)         |
|                                  |
|   오늘 추천을 모두 확인했어요       |
|                                  |
|   추천 거리를 넓히면 더 많은        |
|   분을 만나실 수 있어요            |
|                                  |
|      [ 조건 변경하기 ]            |
|      [ 전국으로 넓히기 ]           |  <- 원클릭 완화 (반경이 전국이 아닐 때만)
|                                  |
```

**Annotations:**
- [1] `전국으로 넓히기`는 가장 흔한 해결책을 **한 번의 탭**으로 제공. 이미 전국이면 숨긴다
- [2] 검수 중·비공개 상태로 추천이 0건인 경우에는 문구를 "프로필이 검수 중이에요"로 교체한다


### 2. 추천 조건

- **Route**: `app/(tabs)/home/filters.tsx`
- **Type**: BottomSheet
- **Pattern**: 폼형

#### Default State

```
+----------------------------------+
|                                  |
|            (dimmed)              |
+----------------------------------+
|            ═════                 |  <- 드래그 핸들 (스와이프 다운 해제)
|  추천 조건                  [닫기] |
+----------------------------------+
|                                  |
|  추천 거리                        |  <- 영향이 가장 큰 조건을 맨 위
|  [10km] [30km] [50km] [전국]      |  <- 세그먼트, 현재값 강조
|                                  |
|  ------------------------------  |
|                                  |
|  나이                             |
|  55 ─────●━━━━━━━━●───── 85       |  <- 범위 슬라이더
|     58세                 72세     |
|                                  |
|  ------------------------------  |
|                                  |
|  혼인 상태                        |
|  (o) 사별과 이혼 모두              |
|  ( ) 사별만                       |
|  ( ) 이혼만                       |
|                                  |
|  ------------------------------  |
|                                  |
|  관계 목적                        |
|  [재혼][진지한 연애][부담없는 데이트]|  <- 다중 선택 칩 (줄바꿈)
|  [여행·취미][동성 친구][식사·산책]  |
|                                  |
|  ------------------------------  |
|                                  |
|  v  더 자세한 조건                 |  <- 접힘: 지역/종교/음주/흡연/경제활동
|                                  |
+----------------------------------+
|  [조건 초기화]  [====적용하기====] |  <- Sticky
+----------------------------------+
```

**Annotations:**
- [1] 순서는 **결과에 미치는 영향 크기** 순: 거리 → 나이 → 혼인상태 → 관계 목적 → 나머지(접힘)
- [2] `더 자세한 조건`은 기본 접힘 (Progressive Disclosure). 값이 설정돼 있으면 개수 배지 표시
- [3] 원하는 상대 성별은 `더 자세한 조건` 안이 아니라 부모님 프로필 등록 시 기본값을 따르고, 여기서 덮어쓴다
- [4] `적용하기`는 Sticky. 시트 스크롤이 버튼 뒤에 가려지지 않도록 하단 inset 72dp
- [5] 조건 변경으로 결과가 0건이면 **시트를 닫지 않고** 인라인 안내 + `전국으로 넓히기` 노출
- **Visual Hierarchy**: 추천 거리 > 적용하기 > 나이 > 혼인상태 > 관계 목적
- **Interaction**: 스와이프 다운으로 해제. 변경 후 미적용 상태로 닫으려 하면 "변경한 조건을 적용하지 않고 닫을까요?" 확인
- **Spacing**: 섹션 간 24, 섹션 내 요소 간 12, 시트 좌우 20

#### Error State

```
|  추천 거리                        |
|  [10km] [30km] [50km] [전국]      |
|  ...                             |
+----------------------------------+
|  (!) 조건을 저장하지 못했어요.      |
|      다시 시도해주세요.            |
|  [조건 초기화]  [====다시 시도====] |
+----------------------------------+
```

**Annotations:**
- [1] 시트를 닫지 않고 **하단 CTA 위 인라인 배너**로 알린다. 입력값을 잃지 않는다

## Tab Navigation Flow

```
[홈: 추천 피드] --필터 아이콘--> [추천 조건 시트] --적용--> [홈: 추천 피드] (갱신)
      |
      +--자세히--> [/profile/[id] 상세 Modal] --하트--> +
      |                                                 |
      +--하트--> (상호 하트?) --예--> [/matched/[id] 시트] --대화 시작--> [매칭 탭: 채팅방]
      |                        --아니오--> 다음 카드
      |
      +--카드 ⋯--> [/report/[id] 신고 시트]
      |
      (알림 화면으로 가는 앱 내 진입점은 없다 — 탭 배지로 대체)
      |
      +--(프로필 미등록) 등록하기--> [(parent-setup)/onboarding]
```
