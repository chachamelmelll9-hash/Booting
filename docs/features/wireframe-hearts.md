## Feature: 하트 & 대화 연결

### 1. 받은 하트

- **Route**: `app/(tabs)/hearts/index.tsx`
- **Type**: Tab
- **Pattern**: 리스트형

#### Default State

```
+----------------------------------+
|  9:41          [=] LTE  100%     |
+----------------------------------+
|  우리 부모님께 관심을 보낸 분        |
+----------------------------------+
|                                  |
|  새로 받은 관심 2                  |  <- 섹션 헤더 13sp, 미읽음 그룹
|                                  |
|  +----------------------------+  |
|  | +------+  이OO, 65세    (new)| |  <- 썸네일 72x88 (4:5), 좌측
|  | |      |  경기 성남 분당구    | |
|  | | [img]|  이혼             | |
|  | |      |  [진지한 연애][여행] | |
|  | +------+  (v)자녀 (v)가족관계 | |
|  |           2시간 전           | |
|  |  ------------------------  | |
|  |    [넘기기]      [ 하트 ]    | |  <- 행 안 인라인 액션, 44pt+
|  +----------------------------+  |
|                                  |
|  +----------------------------+  |
|  | +------+  박OO, 71세    (new)| |
|  | | [img]|  서울 마포구        | |
|  | +------+  사별              | |
|  |           [식사·산책 친구]    | |
|  |           (v)자녀 (v)가족관계 | |
|  |           어제               | |
|  |  ------------------------  | |
|  |    [넘기기]      [ 하트 ]    | |
|  +----------------------------+  |
|                                  |
|  이전에 받은 관심                  |  <- 읽은 그룹, 배경 톤 다운
|                                  |
|  +------+ 최OO, 68세  인천 남동구 |  <- 읽은 항목은 컴팩트 1행
|  | [img]| 사별 · 3일 전          |
|  +------+                    (>) |
|                                  |
+----------------------------------+
|  [홈]  [관심●]  [인연]  [내 정보]  |
+----------------------------------+
```

**Annotations:**
- [1] **미읽음과 읽음의 표현을 다르게 한다** — 미읽음은 사진 큰 카드 + 인라인 액션, 읽음은 1행 컴팩트. 동일 카드 반복은 시각적 피로를 만든다 (anti-patterns.md "모든 리스트가 동일 카드")
- [2] 행 전체 탭 → `/profile/[id]` 상세 Modal. 인라인 `하트`/`넘기기`는 상세를 열지 않고 즉시 처리
- [3] `(new)` 배지는 **탭 진입 시가 아니라 개별 항목을 본 뒤** 해제한다. 탭 배지(●)는 진입 즉시 해제
- [4] 하트 결과가 상호 하트면 `/matched/[id]` 전체화면 시트를 띄운다. 아니면 행을 위로 접으며 제거
- [5] 관계 목적 칩은 최대 2개까지만 (PRD 6장). 넘치면 자르지 않고 프로필 자체가 2개 제한
- **Visual Hierarchy**: 대표사진 > 이름·나이 > 지역·혼인상태 > 관계 목적 > 인증 배지 > 받은 시각
- **Interaction**: 좌 스와이프로 `넘기기` 노출(보조 수단). 주 수단은 버튼. 당겨서 새로고침 지원
- **Spacing**: 화면 좌우 16 / 카드 간 12 / 그룹 헤더 위 24 / 카드 내부 패딩 16
- **Performance**: `FlatList` + `getItemLayout`. 미읽음/읽음은 `SectionList` 대신 단일 리스트 + 헤더 아이템으로 처리해 재정렬 비용을 줄인다

#### Empty State

Common State 사용.

```
|        (하트 아웃라인 아이콘)      |
|                                  |
|   아직 받은 관심이 없어요           |
|                                  |
|   우리 부모님 프로필이 공개되어      |
|   있으면 더 많은 분이 볼 수 있어요   |
|                                  |
|      [ 프로필 상태 보기 ]          |
```

**Annotations:**
- [1] CTA는 `내 정보 > 부모님 프로필 상태`로 보낸다. 프로필이 검수 중이거나 비공개면 그 사실이 원인일 확률이 높다
- [2] 프로필이 아예 없으면 문구를 "부모님 프로필을 먼저 등록해주세요"로, CTA를 `부모님 등록하기`로 바꾼다

Common State 사용 (썸네일 + 3줄 스켈레톤 3행).

Common State 사용.

## Tab Navigation Flow

```
[관심: 받은 하트] --행 탭--> [/profile/[id] 상세 Modal]
       |                            |
       |                            +--하트--> +
       |                                       |
       +--인라인 하트--> (상호 하트?) --예--> [/matched/[id]] --대화 시작--> [인연: 채팅방]
       |                              --아니오--> 행 제거 + 토스트
       |
       +--⋯--> [/report/[id] 신고 시트]
       |
       +--(비어 있음) 프로필 상태 보기--> [내 정보: 부모님 프로필 상태]
```
