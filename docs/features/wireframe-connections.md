# Wireframe: Tab 인연

## Overview

- Tab: 인연
- Pages: 7 (인연 목록, 채팅방, 부모님 의사 확인, 만남 일정, 미동행 확인, 만남 확인, 사후 응답)
- Source Features: 하트 & 대화 연결, 첫 만남 & 최종 매칭 확정

> 이 탭은 PRD 13.5(인연 관리)와 13.6(메시지)을 한 탭의 두 층으로 구현한다.
> 목록 행이 **상태 배지 + 마지막 메시지**를 함께 보여주고, 탭하면 상태에 따라
> 채팅방 또는 만남 화면으로 들어간다.

## Feature: 하트 & 대화 연결

### 1. 인연 목록

- **Route**: `app/(tabs)/connections/index.tsx`
- **Type**: Tab
- **Pattern**: 리스트형

#### Default State

```
+----------------------------------+
|  9:41          [=] LTE  100%     |
+----------------------------------+
|  인연                             |
+----------------------------------+
| [전체 5][대화 중 2][만남 예정 1]... |  <- 가로 스크롤 상태 칩
+----------------------------------+
|                                  |
|  +----------------------------+  |
|  | 만남 확인을 기다려요          |  |  <- 상태 배지가 행의 리드 (18sp Bold)
|  |                            |  |
|  | (o) 이OO, 65세 · 경기 성남   |  |  <- 아바타 40 원형, 이름 15sp
|  |                            |  |
|  | 9/3(수) 오후 2시 · 성남 카페  |  |  <- 다음 할 일/맥락 한 줄
|  |                            |  |
|  |          [====만남 확인====] |  |  <- 행 안 주 액션
|  +----------------------------+  |
|                                  |
|  +----------------------------+  |
|  | 대화 중이에요                |  |
|  |                            |  |
|  | (o) 박OO, 71세 · 서울 마포   |  |
|  | "그럼 다음 주 화요일 어떠세요?" |  |  <- 마지막 메시지 1줄 말줄임
|  | 오후 3:12                (2)|  |  <- 미읽음 카운트
|  +----------------------------+  |
|                                  |
|  +----------------------------+  |
|  | 서로 관심이 있어요            |  |
|  |                            |  |
|  | (o) 최OO, 68세 · 인천 남동   |  |
|  | 아직 대화를 시작하지 않았어요   |  |
|  |                            |  |
|  |          [ 대화 시작하기 ]    |  |
|  +----------------------------+  |
|                                  |
|  +----------------------------+  |
|  | 최종 매칭 성공               |  |  <- 성공은 액센트 색 + 체크 아이콘
|  | (v)                        |  |
|  | (o) 정OO, 66세 · 서울 강동   |  |
|  | 대화방 82일 남음             |  |
|  +----------------------------+  |
|                                  |
+----------------------------------+
|  [홈]  [관심]  [인연●]  [내 정보]  |
+----------------------------------+
```

**Annotations:**
- [1] **상태 배지가 제목이다.** 사용자가 이 화면에서 하는 판단은 "지금 뭘 해야 하나"이므로 이름보다 상태가 먼저 읽혀야 한다
- [2] 상태별로 행의 **구성이 다르다** — 행동이 필요한 상태(만남 확인/대화 시작)는 행 안에 CTA, 대화 중은 마지막 메시지 + 미읽음, 완료는 잔여 기간. 동일 카드 반복 금지
- [3] 상태 칩 순서 = PRD 10.3 진행 순서. 문구는 PRD와 **글자 단위로 일치**시킨다
- [4] 탭 시 이동: 대화 중/서로 관심 → 채팅방, 만남 예정/확인 대기 → 만남 일정, 최종 매칭 → 채팅방
- [5] 미읽음 배지(●)는 새 메시지 또는 행동이 필요한 상태가 있을 때만
- **Visual Hierarchy**: 상태 배지 > 행 안 CTA > 상대 부모님 이름 > 맥락 한 줄 > 시각
- **Interaction**: 당겨서 새로고침. Realtime 구독으로 상태·마지막 메시지 자동 갱신 (전체 리렌더 대신 행 단위 갱신)
- **Spacing**: 좌우 16 / 카드 간 12 / 카드 내부 16 / 상태 배지↔이름 8
- **Performance**: `FlatList`. 상태 칩 필터는 서버 재조회가 아니라 클라이언트 필터(목록 규모가 작다)

#### Empty State

```
|        (연결 아웃라인 아이콘)      |
|                                  |
|   아직 인연이 없어요                |
|                                  |
|   서로 관심을 표현하면              |
|   이곳에서 대화를 시작할 수 있어요   |
|                                  |
|      [ 추천 보러 가기 ]            |
```

**Annotations:**
- [1] 상태 칩으로 걸러 0건인 경우에는 문구를 "이 단계의 인연이 아직 없어요"로 바꾸고 CTA는 `전체 보기`

### 2. 채팅방

- **Route**: `app/(tabs)/connections/[id]/index.tsx`
- **Type**: Stack
- **Pattern**: 고유 (대화)

#### Default State

```
+----------------------------------+
|  9:41          [=] LTE  100%     |
+----------------------------------+
| < (o) 박OO, 71세 · 서울 마포  [...]|  <- 상대 부모님 요약 바 (탭 → 상세)
+----------------------------------+
|  [ 부모님 의사 확인 ]  [ 만남 일정 ]|  <- 단계 액션 바 (상태에 따라 활성)
+----------------------------------+
|  +----------------------------+  |
|  | (i) 전화번호 등 연락처는      |  |  <- 최초 1회 안전 배너
|  |     충분히 확인한 뒤          |  |
|  |     공유해주세요.  [안전수칙>] |  |
|  +----------------------------+  |
|                                  |
|              9월 1일              |
|                                  |
|  +--------------------+          |
|  | 어머니 사진 잘 봤습니다 |          |  <- 받은 메시지: 좌측, 뉴트럴
|  +--------------------+          |
|  오전 10:02                       |
|                                  |
|          +----------------------+ |
|          | 감사합니다. 아버지도    | |  <- 보낸 메시지: 우측, 액센트
|          | 등산을 좋아하세요       | |
|          +----------------------+ |
|                    오전 10:15 (v) |
|                                  |
|          +----------------------+ |
|          | 다음 주 화요일 어떠세요? | |
|          +----------------------+ |
|             오전 10:16 (!) 다시 시도|  <- 전송 실패
|                                  |
+----------------------------------+
|  { 메시지를 입력하세요        } (>)|  <- 입력창 44pt+, safe area
+----------------------------------+
```

**Annotations:**
- [1] 상단 요약 바: 대화는 자녀끼리 하지만 **주제는 부모님**이다. 상대 부모님을 항상 보이게 둔다. 탭 → `/profile/[id]`
- [2] 단계 액션 바: 현재 상태에서 가능한 다음 단계만 활성. `부모님 의사 확인`이 끝나면 `만남 일정`이 활성된다
- [3] 안전 배너: 최초 진입 1회. 닫으면 접히고 `[...]` 메뉴에서 다시 열 수 있다. 매 진입 노출은 무시된다
- [4] 전송 실패는 말풍선 옆 `(!) 다시 시도` — 아이콘 + 텍스트. 토스트로 대체하지 않는다
- [5] `[...]`: 프로필 보기 / 안전수칙 / 신고 / 차단 / 대화 나가기. **파괴적 항목은 구분선 아래 + 위험색**
- [6] 보낸/받은 구분을 색만으로 하지 않는다 — 정렬 + 말풍선 꼬리 방향 병행 (a11y)
- **Visual Hierarchy**: 상대 부모님 요약 바 > 단계 액션 바 > 메시지 > 입력창
- **Interaction**: 키보드 표시 시 입력창이 가려지지 않도록 `KeyboardAvoidingView`. 새 메시지 도착 시 하단 고정이면 자동 스크롤, 위로 읽는 중이면 "새 메시지" 플로팅 버튼
- **Spacing**: 말풍선 좌우 16 / 말풍선 간 8 / 발신자 전환 시 16 / 날짜 구분선 위아래 24
- **Performance**: `FlatList` `inverted` + 페이지네이션. 전체 메시지 `.map()` 금지

#### Empty State

```
|              9월 1일              |
|                                  |
|        대화를 시작해보세요          |
|                                  |
|  [어머니 사진 잘 봤습니다]          |  <- 첫 문장 칩 (탭하면 입력창에 채움)
|  [취미가 비슷하시네요]             |
|  [부모님은 어떤 분이신가요?]        |
|                                  |
```

**Annotations:**
- [1] 첫 문장 칩은 **전송하지 않고 입력창에 채운다** — 사용자가 다듬을 여지를 남긴다

## Feature: 첫 만남 & 최종 매칭 확정

### 3. 부모님 의사 확인

- **Route**: `app/(tabs)/connections/[id]/parent-intent.tsx`
- **Type**: BottomSheet
- **Pattern**: 고유 (3지선다)

#### Default State

```
+----------------------------------+
|            (dimmed)              |
+----------------------------------+
|            ═════                 |
|  부모님 의사 확인            [닫기] |
+----------------------------------+
|                                  |
|  박OO 님을 부모님께 보여드리고      |
|  만나보실 의향을 여쭤봐 주세요.     |  <- 17sp, 이 시트의 목적
|                                  |
|  +----------------------------+  |
|  | (o) 만나보고 싶다고 하세요    |  |  <- 기본 강조(Primary 테두리)
|  +----------------------------+  |
|  +----------------------------+  |
|  | ( ) 조금 더 생각해보신대요    |  |
|  +----------------------------+  |
|  +----------------------------+  |
|  | ( ) 이번엔 어렵다고 하세요    |  |
|  +----------------------------+  |
|                                  |
|  (i) 상대방에게는 결과만 전달되고   |
|      사유는 공유되지 않아요.        |
|                                  |
+----------------------------------+
|  [====부모님 의사 전달하기====]    |
+----------------------------------+
```

**Annotations:**
- [1] 선택지 카드 높이 56pt (터치 타겟). 라디오 점만이 아니라 **카드 전체**가 터치 영역
- [2] `이번엔 어렵다` 선택 후 제출 시 확인 다이얼로그 — 인연이 종료되는 파괴적 동작
- [3] 거절 사유를 묻지 않는다. 상대에게 "이번에는 인연이 닿지 않았어요"만 전달
- **Visual Hierarchy**: 안내 문장 > 선택지 3개 > CTA > 고지 문구

#### Empty/Waiting State

```
|        (모래시계 아이콘)           |
|                                  |
|   상대방의 부모님 의사를            |
|   기다리고 있어요                  |
|                                  |
|   확인되면 알림으로 알려드릴게요     |
|                                  |
|         [ 대화로 돌아가기 ]        |
```

### 4. 만남 일정

- **Route**: `app/(tabs)/connections/[id]/meeting.tsx`
- **Type**: Stack
- **Pattern**: 상세형 + 폼형

#### Default State — 제안 전

```
+----------------------------------+
|  < 뒤로      첫 만남               |
+----------------------------------+
|  +----------------------------+  |
|  | (i) 첫 만남은 자녀와 함께하는  |  |  <- 원칙 배너 (닫히지 않음)
|  |     것을 권해드려요.          |  |
|  +----------------------------+  |
|                                  |
|  날짜와 시간 *                    |
|  +----------------------------+  |
|  { 9월 3일 (수) 오후 2:00     } (달)|
|  +----------------------------+  |
|                                  |
|  만남 장소 *                      |
|  +----------------------------+  |
|  { 성남시 분당구 정자동 ○○카페  }  |
|  +----------------------------+  |
|  (i) 카페·식당 등 사람이 있는       |  <- 영구 helper text
|      공공장소를 권해드려요.         |
|                                  |
|  동행                             |
|  +----------------------------+  |
|  | [x] 저도 함께 갑니다          |  |  <- 기본 체크됨
|  +----------------------------+  |
|                                  |
|  메모 (선택)                      |
|  +----------------------------+  |
|  { 아버지가 오후를 선호하세요     }  |
|  +----------------------------+  |
|                                  |
+----------------------------------+
|  [====만남 일정 제안하기====]      |
+----------------------------------+
```

#### Default State — 확정 후

```
+----------------------------------+
|  < 뒤로      첫 만남               |
+----------------------------------+
|                                  |
|         D-2                      |  <- 40sp, 가장 큼
|   9월 3일 (수) 오후 2:00           |  <- 20sp Bold
|                                  |
|  ------------------------------  |
|                                  |
|  장소                             |
|  성남시 분당구 정자동 ○○카페        |
|                                  |
|  동행                             |
|  양측 자녀 모두 동행               |
|                                  |
|  ------------------------------  |
|                                  |
|  안전수칙                          |
|  · 공공장소에서 만나세요            |
|  · 일정과 장소를 가족과 공유하세요    |
|  · 금전 요구에 응하지 마세요         |
|                       [자세히 >]  |
|                                  |
+----------------------------------+
|  [ 일정 변경 제안 ]                |
|  [====부모님끼리 만났어요====]     |  <- 만남 시각 이후에만 활성
+----------------------------------+
```

**Annotations:**
- [1] 확정 후 화면에서 **가장 먼저 읽혀야 할 것은 D-day와 일시**. 장소는 그다음
- [2] `부모님끼리 만났어요`는 만남 예정 시각 **이전에는 비활성**. 비활성 사유를 버튼 아래 한 줄로 명시("만남 시각 이후에 확인할 수 있어요")
- [3] 동행 체크 해제 → `meeting-solo` 시트가 즉시 열린다 (체크 상태는 시트를 완료해야 바뀐다)
- [4] 상대가 제안한 일정이면 CTA가 `수락하기` / `다른 시간 제안`으로 바뀐다
- [5] 안전수칙 `자세히` → WebView `/safety`
- **Visual Hierarchy**: D-day > 일시 > 장소 > 동행 > 안전수칙
- **Spacing**: 섹션 간 24 / 라벨↔값 4 / 폼 필드 간 16

#### Error State (폼)

Common Inline Field Error 사용 — "지난 날짜는 선택할 수 없어요" / "만남 장소를 입력해주세요"

### 5. 자녀 미동행 확인

- **Route**: `app/(tabs)/connections/[id]/meeting-solo.tsx`
- **Type**: BottomSheet
- **Pattern**: 폼형

#### Default State

```
+----------------------------------+
|            (dimmed)              |
+----------------------------------+
|            ═════                 |
+----------------------------------+
|                                  |
|  첫 만남은 자녀 동행을             |  <- 22sp Bold, 가장 큼
|  강력히 권해드려요                 |
|                                  |
|  부모님만 만나시는 경우 안전 확인이  |
|  어려울 수 있어요.                 |
|                                  |
|  동행이 어려운 이유 *              |
|  +----------------------------+  |
|  { 직장 일정으로 참석이 어렵습니다 } |
|  |                            |  |
|  +----------------------------+  |
|                                  |
|  아래 내용을 확인해주세요           |
|  [ ] 공공장소에서 만나기로 했어요    |
|  [ ] 일정과 장소를 가족과 공유했어요  |
|  [ ] 만남 후 안부를 확인하겠습니다   |
|                                  |
+----------------------------------+
|  [ 다시 생각해볼게요 ]             |
|  [   이해했고 진행할게요   ]        |  <- 체크 3개 + 사유 전까지 비활성
+----------------------------------+
```

**Annotations:**
- [1] 권고 문구가 화면에서 가장 크다. 진행 버튼은 **Primary가 아닌 Secondary** — 권장 경로가 아님을 형태로 말한다
- [2] `다시 생각해볼게요`가 위, 진행이 아래 (기본 경로를 손이 먼저 닿는 곳에)
- [3] 체크박스는 라벨 전체가 터치 영역 (44pt 행 높이)
- [4] 완료 시 사유와 확인 시각을 기록하고, 일정 카드에 **양측 모두에게** '자녀 미동행' 표기
- **Visual Hierarchy**: 권고 문구 > 체크 3개 > 사유 입력 > 진행 버튼

### 6. 만남 확인

- **Route**: `app/(tabs)/connections/[id]/meeting-confirm.tsx`
- **Type**: BottomSheet
- **Pattern**: 결과형

#### Default State — 확인 전

```
+----------------------------------+
|            ═════                 |
|  만남 확인                  [닫기] |
+----------------------------------+
|                                  |
|  9월 3일 (수) 오후 2:00            |
|  성남시 분당구 정자동 ○○카페        |
|                                  |
|  부모님께서 실제로 만나셨나요?       |
|                                  |
|  (i) 양측이 모두 확인해야 최종       |
|      매칭으로 처리돼요.             |
|                                  |
+----------------------------------+
|  [ 만나지 못했어요 ]               |
|  [====부모님끼리 만났어요====]     |
+----------------------------------+
```

#### Waiting State — 내 확인 완료, 상대 대기

```
|                                  |
|        (v) 확인했어요              |
|                                  |
|   상대방의 만남 확인을              |  <- 이 화면의 최상위 정보
|   기다리고 있어요                  |
|                                  |
|   상대방이 확인하면 최종 매칭으로     |
|   전환되고 알림을 보내드릴게요.      |
|                                  |
|   3일 후에도 확인이 없으면          |
|   다시 알려드릴게요.               |
|                                  |
|        [ 인연 목록으로 ]           |
```

#### Success State — 양측 확인 완료

```
|                                  |
|            (v)                   |  <- 스프링 스케일 인 (damping 18)
|                                  |
|      최종 매칭 성공                |  <- 28sp Bold, 액센트
|                                  |
|   부모님 두 분이 만나셨어요.        |
|   앞으로의 시간을 응원할게요.        |
|                                  |
|   대화방은 90일간 유지돼요.         |
|                                  |
|  [====만남은 어떠셨나요?====]      |  <- feedback 시트로
|  [ 나중에 답할게요 ]               |
```

**Annotations:**
- [1] **'최종 매칭 성공'은 서버 응답이 그렇게 올 때만 렌더한다.** 클라이언트가 낙관적으로 이 화면을 띄우지 않는다
- [2] 대기 상태에서 최상위 정보는 "기다리고 있어요" — 사용자가 가장 헷갈려 하는 지점이다
- [3] `만나지 못했어요` → 일정이 취소/재조율 상태로 돌아간다 (확인 기록 없음)
- [4] 성공 화면에 점수·별점·평가 요소를 두지 않는다 (PRD 12.3)
- **Visual Hierarchy(대기)**: 상태 문구 > 설명 > 재알림 안내 > 이동 버튼
- **Interaction**: 성공 시 체크 아이콘만 스프링으로 등장. 무한 반복 애니메이션·컨페티 남발 금지

### 7. 만남 이후 응답

- **Route**: `app/(tabs)/connections/[id]/feedback.tsx`
- **Type**: BottomSheet
- **Pattern**: 결과형

#### Default State

```
+----------------------------------+
|            ═════                 |
|  만남은 어떠셨나요?           [닫기]|
+----------------------------------+
|                                  |
|  +----------------------------+  |
|  | ( ) 인연을 계속 이어가고 싶어요 |  |
|  +----------------------------+  |
|  +----------------------------+  |
|  | ( ) 좋은 친구로 지내고 싶어요  |  |
|  +----------------------------+  |
|  +----------------------------+  |
|  | ( ) 조금 더 생각해볼게요      |  |
|  +----------------------------+  |
|  +----------------------------+  |
|  | ( ) 더 만나지 않을래요        |  |
|  +----------------------------+  |
|                                  |
|  (자물쇠) 이 답변은 상대방에게      |  <- 비공개 고지, 작지만 명확히
|          공개되지 않아요.          |
|                                  |
+----------------------------------+
|  [ 건너뛰기 ]   [====보내기====]  |
+----------------------------------+
```

**Annotations:**
- [1] 비공개 고지는 자물쇠 아이콘 + 문구. 이 고지가 없으면 사용자가 솔직하게 답하지 않는다
- [2] `건너뛰기`를 항상 제공한다 (필수 응답 아님)
- [3] 선택지 순서는 PRD 12.3 순서 그대로. 긍정→부정 순이며 재정렬하지 않는다
- [4] 제출 후 별도 축하·감사 화면 없이 조용히 닫는다. 상대에게 노출되는 어떤 신호도 만들지 않는다
- **Visual Hierarchy**: 질문 제목 > 선택지 4개 > 비공개 고지 > CTA
