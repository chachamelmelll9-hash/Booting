# Wireframe: Modals & Bottom Sheets

탭에 속하지 않는 화면 — 여러 탭에서 공유하는 모달 3개, 알림 1개, 부모님 등록 플로우 5개.

## 1. 상대 부모님 상세 프로필

- **Route**: `app/profile/[id].tsx`
- **Type**: Modal (전체 화면)
- **Triggered From**: 추천 피드, 받은 하트, 채팅방 상단 요약 바
- **Source Feature**: 조건 기반 추천 & 탐색

#### Default State

```
+----------------------------------+
|  [닫기]                     [...]|  <- 사진 위 오버레이 (dim 처리)
|                                  |
|                                  |
|            [img]                 |  <- 사진 캐러셀, 화면 폭 전체
|         대표사진 4:5              |     높이 약 55%
|                                  |
|                                  |
|         · ○ ○ ○                  |  <- 페이지 인디케이터 (4장)
+----------------------------------+
|                                  |
|  텃밭지기, 67세                   |  <- 26sp Bold
|  서울 송파구 · 사별 (2019년)        |  <- 15sp
|                                  |
|  (v)자녀인증 (v)가족관계           |  <- 인증 배지 3종, 접히지 않는 고정 슬롯
|  (v)부모님동의                    |
|                                  |
|  [여행·취미 친구] [진지한 연애]      |
|                                  |
|  ------------------------------  |
|                                  |
|  딸이 소개하는 우리 아버지          |  <- 이 화면의 최상위 콘텐츠
|                                  |
|  등산과 전시 관람을 좋아하세요.      |  <- 전문 표시 (말줄임 없음)
|  퇴직 후에도 새벽마다 산에 오르는    |
|  부지런한 분이에요. 말수는 적지만    |
|  한번 정한 약속은 꼭 지키세요.      |
|                                  |
|  ------------------------------  |
|                                  |
|  이런 분을 찾아요                  |
|  조용한 대화를 좋아하시고 산책을     |
|  즐기시는 분이면 좋겠어요.          |
|                                  |
|  ------------------------------  |
|                                  |
|  아버지의 한마디                   |
|  "건강하게 오래 함께 걸을 분을      |  <- 인용 스타일, 좌측 액센트 바
|   만나고 싶습니다."                |
|                                  |
|  ------------------------------  |
|                                  |
|  생활                             |
|  종교        무교                 |  <- 라벨-값 2열, 균등 3열 금지
|  직업        은퇴 (전 교사)        |
|  경제활동     연금 수령            |
|  음주        가끔                 |
|  흡연        비흡연               |
|                                  |
|  ------------------------------  |
|                                  |
|  가족                             |  <- 이 화면에서만 노출
|  자녀        딸 2명               |
|  동거 가족    혼자 거주             |
|                                  |
|  ------------------------------  |
|                                  |
|  사주                             |  <- 공개 설정한 경우만
|  1959년 3월 12일 (음력)            |
|  출생시각 모름                     |
|                                  |
+----------------------------------+
|     [넘기기]        [ 하트 ]      |  <- Sticky, 하트가 우세
+----------------------------------+
```

**Annotations:**
- [1] **가장 먼저 읽혀야 할 것은 "딸이 소개하는 우리 아버지"** 소개글이다. 이 서비스가 다른 소개팅 앱과 다른 지점이므로 스펙·조건보다 위에 둔다
- [2] 소개글 제목은 자녀의 성별·부모 성별에 따라 동적 생성("딸이 소개하는 우리 아버지" / "아들이 소개하는 우리 어머니")
- [3] 생활·가족은 **라벨-값 2열**. 균등 3열 카드 그리드 금지 (anti-patterns.md)
- [4] 자녀 수·동거 가족은 이 화면에만 있다 — 카드와 필터에는 절대 노출하지 않는다 (PRD 8.2)
- [5] 미입력 섹션은 **섹션째로 숨긴다**. 빈 값이나 "정보 없음" 노출 금지
- [6] `[...]`: 신고 / 차단. 사진 위 오버레이라 대비 확보용 그라디언트 필요
- [7] 채팅방에서 진입한 경우 하단 Sticky는 `하트/넘기기` 대신 `[ 대화로 돌아가기 ]`로 바뀐다
- **Visual Hierarchy**: 대표사진 > 이름·나이 > 자녀 소개글 > 인증 배지 > 관계 목적 > 생활 > 가족 > 사주
- **Interaction**: 사진 좌우 스와이프. 아래로 당겨 닫기. 스크롤 시 상단에 이름이 축약 헤더로 고정

#### Error State — 비공개 전환

```
|        (자물쇠 아이콘)            |
|                                  |
|   이 프로필은 현재                 |
|   공개되지 않았어요                |
|                                  |
|   부모님이 공개를 중단하셨거나      |
|   검토 중일 수 있어요.             |
|                                  |
|        [ 목록으로 ]               |
```

## 2. 상호 하트 시트

- **Route**: `app/matched/[id].tsx`
- **Type**: Modal (전체 화면)
- **Triggered From**: 추천 피드·받은 하트에서 하트 전송 결과가 상호 하트일 때
- **Source Feature**: 하트 & 대화 연결

#### Default State

```
+----------------------------------+
|                            [닫기]|
|                                  |
|                                  |
|      서로 관심이 있어요            |  <- 28sp Bold. '매칭'이라는 단어 없음
|                                  |
|                                  |
|     +--------+  +--------+       |
|     |        |  |        |       |  <- 두 부모님 사진, 살짝 겹치게
|     | [img]  |  | [img]  |       |     좌측이 우리 부모님
|     |        |  |        |       |
|     +--------+  +--------+       |
|      우리 아버지    이OO, 65세      |
|                                  |
|                                  |
|   이제 자녀분들끼리 대화를          |
|   시작할 수 있어요.                |
|                                  |
|   부모님께 소개하기 전에            |
|   서로를 확인해보세요.             |
|                                  |
|                                  |
+----------------------------------+
|  [====대화 시작하기====]          |
|  [ 나중에 할게요 ]                 |
+----------------------------------+
```

**Annotations:**
- [1] **'매칭', '매칭 성공' 문구를 쓰지 않는다** (PRD 10.1). 이 화면은 성공이 아니라 시작이다
- [2] 본문이 다음 단계를 설명한다 — 사용자가 "이제 뭘 하지"에서 멈추지 않게
- [3] `나중에 할게요`도 인연 목록에 '서로 관심이 있어요' 상태로 남는다 (사라지지 않음을 CTA 아래 한 줄로 안내)
- [4] 사진 2장은 **겹치는 비대칭 배치**. 균등 2분할 금지
- [5] 등장 애니메이션: 사진 2장 스태거 스프링(`damping: 18`, 60ms 간격). 컨페티·무한 반복 금지
- **Visual Hierarchy**: "서로 관심이 있어요" > 두 사진 > 다음 단계 설명 > CTA

## 3. 신고

- **Route**: `app/report/[id].tsx`
- **Type**: BottomSheet
- **Triggered From**: 추천 카드 ⋯, 상세 ⋯, 채팅방 ⋯
- **Source Feature**: 조건 기반 추천 & 탐색 / 하트 & 대화 연결

#### Default State

```
+----------------------------------+
|            (dimmed)              |
+----------------------------------+
|            ═════                 |
|  신고하기                   [닫기] |
+----------------------------------+
|                                  |
|  어떤 문제가 있었나요?             |
|                                  |
|  ( ) 허위 정보 (혼인 상태 등)       |
|  ( ) 사진 도용·신분 사칭           |
|  ( ) 금전 요구                    |
|  ( ) 대출·투자 권유               |
|  ( ) 보험·상품 판매               |
|  ( ) 성적 불쾌감을 주는 메시지       |
|  ( ) 거절 후 반복적인 연락          |
|  ( ) 기타                        |
|                                  |
|  자세한 내용 (선택)                |
|  +----------------------------+  |
|  {                            }  |
|  +----------------------------+  |
|                                  |
|  [ ] 이 사용자를 함께 차단할게요     |  <- 기본 체크
|                                  |
+----------------------------------+
|  [====신고하기====]               |  <- 위험색
+----------------------------------+
```

**Annotations:**
- [1] 사유 목록은 PRD 14장 금지행위와 1:1 대응한다. 신고자가 고르기 쉬운 구체적 표현
- [2] `함께 차단`을 기본 체크 — 신고할 만한 상대를 계속 보고 싶은 사용자는 없다
- [3] `기타` 선택 시 자세한 내용이 **필수**로 바뀐다
- [4] 제출 후 해당 프로필을 즉시 목록·추천에서 제거하고 토스트 "신고를 접수했어요. 확인 후 조치해드릴게요."
- **Visual Hierarchy**: 질문 > 사유 목록 > CTA > 상세 입력 > 차단 체크

## 4. 알림

- **Route**: `app/(tabs)/notifications/index.tsx` (탭바에서 `href: null`)
- **Type**: Stack
- **Triggered From**: 홈 헤더 종 아이콘
- **Source Feature**: 하트 & 대화 연결 / 첫 만남 & 최종 매칭 확정
- **Reuse**: Existing — 알림 타입만 교체

#### Default State

```
+----------------------------------+
|  < 뒤로      알림          [모두 읽음]|
+----------------------------------+
|                                  |
|  오늘                             |
|                                  |
|  (하트) 우리 부모님께 관심을        |  <- 미읽음: 좌측 액센트 바
|         보낸 분이 있어요           |
|         2시간 전                  |
|                                  |
|  (연결) 서로 관심이 있어요          |  <- '매칭 성공' 아님
|         이OO 님과 대화를           |
|         시작할 수 있어요           |
|         5시간 전                  |
|                                  |
|  이번 주                          |
|                                  |
|  (달력) 내일 첫 만남이 있어요       |
|         장소와 시간을 다시          |
|         확인해주세요               |
|         어제                      |
|                                  |
|  (체크) 프로필 검수가 완료되어       |
|         공개되었어요               |
|         3일 전                    |
|                                  |
+----------------------------------+
```

**Annotations:**
- [1] **상호 하트 알림에 '매칭 성공'을 쓰지 않는다** (PRD 16장). 문구는 "서로 관심이 있어요"
- [2] 알림 종류별 아이콘은 벡터 세트. 이모지 금지
- [3] 탭하면 해당 대상 화면으로 딥링크 (하트→관심 탭, 연결→채팅방, 만남→만남 일정, 검수→프로필 상태)
- [4] 미읽음은 좌측 액센트 바 + 배경 톤. 색만으로 구분하지 않도록 굵기도 다르게

# 부모님 등록 플로우 `(parent-setup)`

탭 밖 Modal 그룹. 6단계 선형 플로우이며 상단에 진행률을 고정한다.

## 5. 등록 안내

- **Route**: `app/(parent-setup)/onboarding.tsx` · **Type**: Modal(Stack)
- **Source Feature**: 부모님 프로필 등록 & 동의

#### Default State — 안내 3장

```
+----------------------------------+
|  [닫기]                          |
+----------------------------------+
|                                  |
|                                  |
|        (일러스트 영역)             |
|                                  |
|                                  |
|                                  |
|  booting                         |  <- 워드마크, 민트, 배경 도형 없음
|  우리 부모님 소개팅,               |  <- 24sp Bold. '부'와 '팅'만 민트
|  직접 주선해주세요                 |     ('부팅' = 부모님 + 소개팅)
|                                  |
|  프로필 작성도, 상대를 고르는 일도   |  <- 15sp, 2-3줄
|  자녀분이 대신 해주세요.            |
|                                  |
|                                  |
|            ● ○ ○                 |
+----------------------------------+
|  [====다음====]                  |
+----------------------------------+
```

> **브랜드 문구 위치**: 워드마크 `booting` + 태그라인 *우리 **부**모님 소개**팅**, 직접
> 주선해주세요*는 **이 화면에만** 둔다. 홈 헤더에는 워드마크만 놓는다 — 매 화면에
> 태그라인을 반복하면 광고 문구처럼 읽힌다.
>
> **광고 없음 문구는 쓰지 않는다.** AdMob·인앱결제를 켜지 않는 것은 그대로지만(TODO-10),
> 그걸 화면에서 자랑하지는 않는다. 안내 항목은 `전면 무료입니다.`까지만 적는다.

3장의 메시지:
1. **부모님을 가장 잘 아는 사람은 자녀입니다** — 자녀의 역할
2. **공개와 만남은 부모님이 정하세요** — 부모님의 결정권
3. **첫 만남은 자녀와 함께** — 안전 원칙

#### Default State — 혼인 상태 확인 (4번째 화면)

```
+----------------------------------+
|  [닫기]                          |
+----------------------------------+
|                                  |
|  부모님의 현재 혼인 상태를          |
|  알려주세요                       |
|                                  |
|  등록은 사별 또는 이혼인 경우에만    |
|  가능해요.                        |
|                                  |
|  +----------------------------+  |
|  | ( ) 사별                    |  |
|  +----------------------------+  |
|  +----------------------------+  |
|  | ( ) 이혼                    |  |
|  +----------------------------+  |
|  +----------------------------+  |
|  | ( ) 별거 또는 그 외          |  |
|  +----------------------------+  |
|                                  |
+----------------------------------+
|  [====다음====]                  |
+----------------------------------+
```

#### Blocked State — 자격 미달

```
|        (안내 아이콘)              |
|                                  |
|   지금은 등록하실 수 없어요         |
|                                  |
|   법적으로 혼인 관계가 유지되고      |
|   있는 경우에는 등록할 수 없습니다.  |
|                                  |
|   상황이 달라지면 언제든            |
|   다시 찾아주세요.                 |
|                                  |
|        [ 돌아가기 ]               |
```

**Annotations:**
- [1] 안내는 **한 장에 한 메시지**. 3장 모두 좌측 정렬 (중앙 정렬 남발 금지)
- [2] 자격 미달 화면은 비난하는 어조를 쓰지 않는다. 계정은 유지하고 재시도 가능
- [3] 진행률 인디케이터(● ○ ○)는 안내 3장에만. 이후 단계는 상단 스텝 바로 전환

## 6. 인증 센터

- **Route**: `app/(parent-setup)/verification.tsx` · **Type**: Modal(Stack)

#### Default State

```
+----------------------------------+
|  [닫기]     인증          1/3     |
|  [██████░░░░░░░░░░░░░░░░]         |  <- 진행률 바
+----------------------------------+
|                                  |
|  본인 확인이 필요해요               |
|                                  |
|  안전한 서비스를 위해 자녀분의       |
|  신원과 가족관계를 확인해요.        |
|                                  |
|  +----------------------------+  |
|  | (1) 휴대폰 본인인증          |  |
|  |                            |  |
|  |     [ 인증하기 ]            |  |  <- 현재 단계만 활성
|  +----------------------------+  |
|                                  |
|  +----------------------------+  |
|  | (2) 가족관계 인증      (흐림) |  |  <- 이전 단계 완료 전 비활성
|  |                            |  |
|  |     가족관계증명서를 제출해요  |  |
|  +----------------------------+  |
|                                  |
|  (자물쇠) 제출하신 서류는 인증       |
|          목적으로만 쓰이고           |
|          다른 사용자에게            |
|          공개되지 않아요.           |
|                                  |
+----------------------------------+
```

#### State — 가족관계 제출

```
|  +----------------------------+  |
|  | (v) 휴대폰 본인인증    완료   |  |
|  +----------------------------+  |
|                                  |
|  +----------------------------+  |
|  | (2) 가족관계 인증            |  |
|  |                            |  |
|  |  +----------------------+  |  |
|  |  |                      |  |  |
|  |  |    (문서 아이콘)       |  |  |  <- 점선 업로드 영역
|  |  |  가족관계증명서 올리기   |  |  |
|  |  |                      |  |  |
|  |  +----------------------+  |  |
|  |                            |  |
|  |  [ 사진 촬영 ] [ 파일 선택 ] |  |
|  +----------------------------+  |
|                                  |
|  발급 3개월 이내 서류를 올려주세요.  |  <- 영구 helper text
+----------------------------------+
|  [====제출하기====]               |
+----------------------------------+
```

**Annotations:**
- [1] 2단계 체크리스트. **현재 해야 할 항목만 활성**, 나머지는 흐리게 (Progressive Disclosure)
- [2] 민감정보 고지를 자물쇠 아이콘과 함께 화면에 상주시킨다. 이게 없으면 증명서를 올리지 않는다
