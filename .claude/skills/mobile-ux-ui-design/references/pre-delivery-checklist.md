# Pre-Delivery Checklist

UI 코드 배포 전 반드시 검증하는 항목. 모든 항목을 통과해야 배포 가능.

## Visual Quality

- [ ] 이모지를 아이콘으로 사용하지 않음 (벡터 아이콘 사용)
- [ ] 모든 아이콘이 일관된 패밀리와 스타일
- [ ] 공식 브랜드 에셋을 올바른 비율과 여백으로 사용
- [ ] 프레스 상태가 레이아웃 바운드를 시프트하지 않음
- [ ] 시맨틱 테마 토큰 일관 사용 (화면별 하드코딩 색상 없음)
- [ ] AI 기본 패턴 회피 (보라색 그라디언트, Inter Display, 균등 3열 카드 등)
- [ ] borderRadius 시스템이 일관적 (모든 곳에 16 아님)

## Interaction

- [ ] 모든 터치 요소에 명확한 프레스 피드백 (opacity/scale/ripple)
- [ ] 터치 타겟 ≥ 44×44pt (iOS) / ≥ 48×48dp (Android)
- [ ] 마이크로 인터랙션 150-300ms, 스프링 이징
- [ ] 비활성 상태가 시각적으로 명확하고 비인터랙티브 (opacity 0.38-0.5)
- [ ] 스크린리더 포커스 순서가 시각적 순서와 일치
- [ ] 제스처 충돌 없음 (탭/드래그/백스와이프)
- [ ] 시스템 제스처 차단 없음

## Light/Dark Mode

- [ ] 주요 텍스트 대비 ≥ 4.5:1 (라이트 & 다크 모두)
- [ ] 보조 텍스트 대비 ≥ 3:1 (라이트 & 다크 모두)
- [ ] 구분선/보더와 인터랙션 상태가 양쪽 모드에서 구분 가능
- [ ] 모달 스크림 40-60% 블랙
- [ ] 양쪽 테마 모두 실제 디바이스에서 테스트 완료

## Layout

- [ ] Safe area 준수 (헤더, 탭바, 하단 CTA)
- [ ] 스크롤 콘텐츠가 고정/스티키 바 뒤에 숨기지 않음
- [ ] 소형 폰 (375pt), 대형 폰 (428pt), 태블릿 (세로+가로) 검증
- [ ] 디바이스 크기/방향별 수평 여백 적절
- [ ] 4/8dp 스페이싱 리듬 유지
- [ ] 긴 텍스트가 대형 디바이스에서 읽기 좋은 너비

## Accessibility

- [ ] 모든 의미있는 이미지/아이콘에 `accessibilityLabel`
- [ ] 폼 필드에 라벨, 힌트, 명확한 에러 메시지
- [ ] 색상이 유일한 정보 전달 수단이 아님
- [ ] `isReduceMotionEnabled` 시 애니메이션 축소/비활성화
- [ ] Dynamic Type 최대 크기에서 레이아웃 깨짐 없음
- [ ] `accessibilityRole`, `accessibilityState` 올바르게 설정

## States

- [ ] 모든 데이터 화면에 Loading / Empty / Error / Success 상태 구현
- [ ] 스켈레톤 로더가 실제 레이아웃 크기와 매칭
- [ ] 에러 메시지에 원인 + 해결 방법 + 재시도
- [ ] 빈 상태에 행동 유도 CTA
- [ ] 폼 제출 시 로딩 → 성공/실패 피드백

## Performance

- [ ] 50+ 아이템 리스트에 FlatList/FlashList 가상화
- [ ] 애니메이션이 transform/opacity만 사용
- [ ] 비동기 콘텐츠에 공간 예약 (레이아웃 점프 방지)
- [ ] 터치 피드백 100ms 이내
- [ ] `StyleSheet.create` 사용 (인라인 스타일 객체 아님)
- [ ] 불필요한 리렌더 방지 (React.memo, useCallback)

## Navigation

- [ ] 뒤로가기 시 스크롤/상태 보존
- [ ] 모든 주요 화면 딥링크 도달 가능
- [ ] 모달/시트에 명확한 닫기 어포던스
- [ ] 현재 위치가 네비게이션에서 시각적으로 명확
